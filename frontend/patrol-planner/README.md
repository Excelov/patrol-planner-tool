# 巡线规划小工具

面向市政燃气、给排水、热力管线巡检，以及无人车、机动车和电动车巡查路线规划。

当前公开版采用**人工地图加点**：用户按现场道路顺序设置起点、途经点和终点，高德负责相邻点之间的道路连接，本工具负责管线图层、任务点、覆盖统计、方案保存和路线导出。自动管线选点、全局优化和自动补点暂未启用。

## 功能

- DXF / GeoJSON 管线导入和坐标系确认
- 管线、阀井、阀门、调压设施、标志桩等任务点管理
- 道路点、任务点、自由点人工加点
- 点击已有点后，在其后插入新点，后续序号自动顺延
- 高德道路匹配和路线规划
- 超过高德单次途经点限制时自动分段（授权版）
- 道路走廊管线覆盖率、任务点到达率和绕行诊断
- 方案保存、查看、修改和累计覆盖统计
- GPX、KML、CSV 导出和路线图片分享
- Windows 便携版和单文件安装包

## 安装和启动

### Windows 安装包

下载安装包后直接安装并启动。首次使用前需要配置自己的高德 Key。

### 源码运行

要求 Python 3.10+，运行小工具不需要 npm、数据库或 Pig 系统：

```powershell
.\scripts\start-patrol-planner.ps1
```

默认地址：`http://127.0.0.1:8787`

## 高德 Key 配置

公开仓库和安装包不包含任何高德 Key。用户需要在高德开放平台申请自己的 Key，并设置地图 JS Key、安全密钥和 Web 服务 Key。

Windows 安装包用户创建文件：`%LOCALAPPDATA%\PatrolPlanner\amap.local.ps1`

```powershell
Set-Item Env:VITE_AMAP_WEB_JS_KEY -Value 'YOUR_JS_API_KEY'
Set-Item Env:VITE_AMAP_SECURITY_JS_CODE -Value 'YOUR_SECURITY_CODE'
Set-Item Env:AMAP_WEBSERVICE_KEY -Value 'YOUR_WEBSERVICE_KEY'
```

源码用户也可以使用 `vendor/pig-ui/.env.local` 或 `config/local/amap.local.ps1`。配置完成后重新启动本地服务并刷新页面。

## 第一次使用步骤

1. 启动应用并确认地图正常显示。
2. 在“导入 DXF / GIS 图层”中选择文件。
3. 选择源坐标系、投影带号和中央子午线。
4. 预览管线与高德道路是否基本重合，确认或校准整体偏移。
5. 选择需要巡检的管线和设施任务点。
6. 点击“地图加点”，按实际行驶顺序添加道路点、任务点或自由点。
7. 遇到路口时，在转弯前后分别加控制点，避免高德自动绕行。
8. 设置载具、路线长度上限、返回起点和管线邻近距离。
9. 点击“生成道路巡线方案”。
10. 检查路线顺序、覆盖率、未覆盖管段和道路诊断。
11. 保存为线路 1、线路 2 等方案，在“方案管理”中查看和修改。
12. 导出 GPX、KML、CSV 或生成路线图片。
