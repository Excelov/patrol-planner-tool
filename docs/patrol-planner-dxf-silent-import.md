# DXF/GIS 静默导入方案

## 目标

用户在页面选择 DXF 后，不运行命令、不手工搬运中间文件，系统在本机后台完成：解析 → 坐标转换 → 管线/设施分类 → GeoJSON 图层生成 → 坐标核查 → 地图预览 → 手工点位规划。

## 推荐架构

```text
浏览器选择 DXF
  ↓ POST /api/import/dxf（仅回环地址）
本地 Python 导入服务
  ├─ ezdxf 读取 LINE/LWPOLYLINE/POLYLINE/INSERT
  ├─ 图层和块属性分类
  ├─ pyproj 完成 CGCS2000/WGS84/投影坐标转换
  ├─ 生成计算管线 GeoJSON 和设施 Point GeoJSON
  └─ 返回批次、统计、坐标核查报告
  ↓
前端加载 GCJ-02 图层并显示核查结果
  ↓
用户确认后选择管线、加入设施任务点、手动地图加点、调用高德规划
```

所有中间文件存放在本机临时目录或用户指定项目目录，不上传 DXF 和管线坐标。

## 坐标核查闸门

1. 读取 DXF extents，判断经纬度还是投影平面坐标。
2. 优先读取用户选择的坐标系；自动推测只作为建议。
3. 投影坐标必须要求中央经线/带号、单位和基准确认后才转换。
4. 转换到 WGS84/CGCS2000 经纬度后，再转换为 GCJ-02 供高德使用。
5. 在地图上显示边界框、中心点、坐标范围和异常点数量。
6. 坐标核查未通过时只显示预览，不允许进入路线规划。
7. 记录 `sourceCrs`、`targetCrs`、转换参数、导入时间、文件哈希和软件版本。

## 要素分类

- 管线：LINE、LWPOLYLINE、POLYLINE，以及配置映射的管线图层。
- 设施点：INSERT 块、POINT、文字标注；按块名、图层名、编码和属性识别阀门、阀井、调压设施、标志桩、阴保桩。
- 未识别对象：保留在核查报告中，不静默丢弃；用户可下载待映射清单。
- 分类规则放在 `data/gis/templates/cad_layer_mapping_template.csv`，用户可以补充单位自有图层和块名。

## 用户体验

- 文件框支持 `.dxf`、`.geojson`、`.json`。
- 选择 DXF 后显示“正在本机解析”，完成后显示：管线数、设施点数、未识别对象、坐标系和边界。
- 坐标系不确定时弹出一次确认；已保存过的项目可复用配置并静默执行。
- 转换失败显示具体原因和修复建议，不再表现为无响应。
- 导入批次可撤销、重做和重新加载；原始 DXF 永远保留，计算层可重建。

## 依赖与打包

开发环境安装 `ezdxf`、`pyproj`；桌面版将依赖和 Python 运行时一起打包。GitHub 源码提供安装清单和 GeoJSON 示例，不提交真实 DXF。无法安装依赖时，页面提供 GeoJSON 备用导入，不阻塞已有路线规划。

## 实施顺序

1. 将现有 DXF 提取脚本封装为纯函数，输出统一导入批次结构。
2. 增加 `/api/import/dxf` 和 `/api/import/{batch}/preview` 本地接口。
3. 扩展 INSERT/POINT/文字设施识别和图层映射。
4. 接入坐标核查闸门和前端进度/统计面板。
5. 用现有 DXF 做端到端验收，再打包依赖。
