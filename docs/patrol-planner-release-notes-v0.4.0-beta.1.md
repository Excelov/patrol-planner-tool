# 巡线工坊 v0.4.0-beta.1

## 发布内容

- Windows 单文件便携版和 Inno Setup 安装器。
- 应用内 DXF 导入、坐标系确认、管线与设施图层加载。
- 手工点位顺序控制、任意点后插入、超过高德限制自动分段。
- 人工路线覆盖率、任务点到达率和道路诊断。
- GPX、KML、CSV 导出与带途经点编号的路线图片分享。
- 脱敏源码包和合成 GIS 示例数据。

## 快速开始

1. 安装 `patrol-planner-0.4.0-beta.1-setup.exe`，或解压便携 ZIP。
2. 启动“巡线工坊”，在配置页填写高德浏览器 Key、安全密钥和 WebService Key。
3. 导入 DXF，确认源坐标系和投影带号；核查通过后加载管线图层。
4. 手工添加道路控制点，按现场通行顺序调整点位。
5. 生成道路巡线方案，检查覆盖率、道路贴合度、绕行和掉头诊断。

## 校验

请使用 `release/SHA256SUMS-v0.4.0-beta.1.txt` 校验下载文件。真实 DXF、GIS 台账、企业映射表、高德密钥和许可证私钥不在发布包中。

## 已知限制

- 高德道路规划需要联网和有效配额。
- 道路侧别、中央隔离和掉头合法性仍需结合高德返回结果人工确认。
- 自动管线草稿、双侧候选和全局优化暂不启用。
- 本版本为 beta 验收版，正式商业授权和订阅服务尚未开放。
