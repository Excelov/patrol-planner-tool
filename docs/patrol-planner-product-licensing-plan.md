# Windows 桌面版与在线服务的产品选择、版权和收费方案

## 推荐结论：双轨，而不是二选一

### Windows 桌面版

适合燃气、城建和测绘客户：

- DXF/GIS 和路线数据保存在客户电脑或内网
- 可无网完成数据导入、坐标核查和路线编辑
- 高德算路联网时只发送必要的点位和策略
- 以安装包和许可证授权收费

### 在线 SaaS

适合通用巡查、旅游路线和路书用户：

- 注册账户、项目和团队协作
- 在线保存路线、分享和移动端访问
- 服务端统一管理高德 Key、任务和用量
- 以订阅收费

### 为什么采用双轨

真实市政管线数据通常不适合上传公共云端；旅游和普通巡查用户又不需要复杂的本地部署。桌面版解决数据安全，SaaS 解决推广和规模化收费，二者共用路线、点位、轨迹和路书数据格式。

## 桌面版版权和授权

桌面程序本身不是“小程序”，应作为软件产品管理：

- 软件著作权登记：源代码、界面和数据模型留存版本证据。
- 商标：注册产品名称和 Logo。
- 专利/商业秘密：覆盖率、道路侧别和合法折返等独特算法先留技术交底，不直接公开核心规则。
- 许可证：首次启动生成设备指纹，导入签名许可证文件，控制版本、有效期、功能和设备数。
- 离线授权：企业客户使用一年期签名许可证；到期后可续期，不要求上传管线资料。
- 防篡改：许可证使用非对称签名，客户端只内置公钥；Key、许可证私钥和企业数据不进入 GitHub。

桌面版收费可以采用：

1. 个人版：一次性买断基础功能，限制版本升级。
2. 专业版：年授权，包含 DXF/GIS、GPX、路书和升级服务。
3. 企业版：按设备/组织授权，支持内网部署、审计和定制。

## SaaS 版权和收费

- 账户、组织、项目和数据按租户隔离。
- 订阅状态、功能权限和调用次数全部由后端判断。
- 采用月付/年付，按席位、路线规划次数和存储容量计费。
- 企业版可选择专属实例或私有云，数据不与普通租户混用。
- 客户上传的 DXF、GIS 和路线数据归客户；平台只取得提供服务所需的处理权。

## GitHub 开源边界

公开仓库可以放：

- 不含密钥的客户端代码
- 脱敏示例数据
- 本地启动脚本和接口文档
- MIT/Apache-2.0 等明确许可证（需先确认商业策略）

不公开：

- 高德 Key 和安全密钥
- 真实管线和设施数据
- 企业块名映射表
- 服务器端计费、授权签发和核心优化算法

## 当前研发顺序

1. 先完成本地 DXF 直读和坐标核查。
2. 使用 PyInstaller 生成 Windows 便携包，再做安装器。
3. 加入签名许可证校验，但开发版保留本地测试授权。
4. 稳定数据模型后再建设 SaaS 账户和订阅后端。
5. 桌面版和 SaaS 共享导入批次、路线、轨迹和路书格式。
