# 巡线工坊产品化、版本与知识产权规划

更新：2026-09-15

## 当前版本：v0.3.0-alpha

当前阶段只保留“手动地图加点 → 高德机动车/电动车分段算路 → 路线复核”。区域自动选管线和沿管线自动生成草稿点已隐藏，底层代码暂保留，待道路匹配和覆盖率验证成熟后再启用。

## 版本路线

- **v0.3 alpha（当前）**：DXF 转换后的 GeoJSON/CSV 初始数据；手工道路点、任务点、自由点；高德分段路线；本地草稿和 GeoJSON 导出。
- **v0.4 beta**：道路吸附校验、道路侧别、任务点与行驶点分离；路线分段诊断；导入数据质量报告。
- **v0.5 GIS**：导入 Shapefile/GeoPackage/PostGIS 导出表；字段映射、坐标系选择、拓扑检查；区域选择重新开放。
- **v1.0**：路线覆盖率、合法折返、车辆限制、巡检记录和路书生成稳定后发布首个公开版本。

每次版本变更使用 Git tag（如 `v0.3.0-alpha.1`），功能开发走 `feature/*` 分支，稳定版本合并到 `main`，发布前保留变更日志和可回滚构建包。

## 产品打包路线

1. **本地版**：保留 Python 本地服务 + 静态前端，提供启动脚本和示例数据。
2. **桌面版**：使用 Tauri 或 Electron 将前端、本地服务和数据目录打包，API Key 放在用户本机配置，不写入仓库。
3. **Web/GitHub 版**：公开不含敏感管线数据的源码和脱敏示例；用户自行配置高德 Key；提供 Docker 或一键启动包。
4. **移动小程序**：待算法稳定后，再评估微信小程序/uni-app。小程序只负责点位采集、任务下发和路书查看，复杂 DXF/GIS 处理留在桌面或服务端。

## 数据与授权

- DXF、管线坐标、阀室和市政道路资料默认属于业务数据，不随开源代码发布。
- 公开仓库只放脱敏、缩小范围的示例数据，删除真实坐标、单位名称和设备属性。
- 高德地图 JS Key、WebService Key、Security Code 只通过本地 `.env` 或配置文件注入，禁止提交 Git；发布版增加域名白名单、配额和 Key 轮换说明。
- 高德底图、路线结果、坐标转换和接口服务遵守高德开放平台协议，产品宣传中注明第三方服务来源，不把高德数据包装为自有数据。
- 导入的 DXF/GIS 数据必须确认来源、测绘成果使用权、保密等级和对外授权范围；企业部署采用书面授权和数据留存期限。

## 知识产权清单

- 自研代码、路线分段拼接、覆盖率评估、任务点模型、路书模板：保留著作权，建立 Git 提交和版本归档证据。
- 产品名称、Logo、界面视觉：申请商标和作品著作权，先做名称检索。
- 独特的巡线覆盖、道路侧别和折返优化方法：先形成技术文档和发明点清单，再决定专利或商业秘密保护；未评估前不在公开仓库披露核心参数。
- 合作单位数据接口和字段映射：通过合同明确数据使用、再授权、脱敏和终止后的删除义务。

## 发布前检查

- 依赖和许可证扫描；第三方图标、字体、地图 SDK 留存许可证。
- Key、真实管线数据、日志和导出文件脱敏。
- 完成本地、桌面打包和公开示例三套验收。
- 编写《最终用户许可协议》《隐私政策》《数据授权说明》《高德服务使用说明》。
