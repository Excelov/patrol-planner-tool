# 巡线工坊多轮实施计划

## Round 1：手动控制模式（当前轮）

- 用户点位顺序是最高优先级，系统不自动重排。
- 任务点、道路点、自由点保留独立类型。
- 支持在任意已选点之后插入新点，后续点位自动顺延。
- 在弯道路口前后增加控制点提示，避免高德自行选择绕行道路。
- 高德只负责相邻控制点之间的道路合规连接。
- 结果页显示人工顺序、任务点到达率、路线覆盖率和绕行诊断。

验收：18 点以内、超过 18 点分段、局部插入、道路外任务点、闭环和手工回放。

## Round 2：道路控制点与路线诊断

- 保存每个控制点的来源、类型、插入位置和道路匹配状态。
- 对高德返回的每一段记录道路名、转向、距离和异常原因。
- 增加“路口前后控制点”标记和局部重算。
- 增加绕行率、顺序保持率、任务点到达率指标。

验收：复现现有红圈绕行案例，并能指出是吸附偏差、道路限制还是点位不足。

## Round 3：管线走向自动草稿

- 对 DXF/GIS 管线做端点合并、拓扑分组和方向提取。
- 提取端点、分叉点、急转弯和跨路点。
- 按长度采样管线控制点，寻找最近可行驶道路。
- 在道路路口前后生成密集控制点。
- 输出“待用户确认”的道路控制点序列，不直接生成最终路线。

验收：使用现有 DXF，比较自动草稿与人工 18 点方案的覆盖率和绕行率。

## Round 4：覆盖驱动的自动迭代

- 以管线覆盖率和任务点到达率作为硬约束。
- 对未覆盖管段自动补点。
- 双侧管线生成去程/回程候选。
- 对重复道路和非法折返进行惩罚。
- 多次调用高德，保留段间连接关系。

验收：典型市政区域覆盖率达到 95% 以上，异常路线可解释。

## Round 5：发布与收费版本

- 手动模式作为免费试用版核心功能。
- 自动草稿、设施识别和累计覆盖作为专业版功能。
- 企业版增加映射表、权限、私有部署和许可证。
- 完成 Windows 安装器、脱敏样例、文档和 GitHub 发布。

## 不变原则

- 不把高德的“最短路线”称为巡线最优。
- 不改变用户明确给出的点位顺序。
- 自动模式只生成草稿，必须经过用户确认。
- 高德 Key、真实 DXF 和企业映射表不进入公开仓库。
