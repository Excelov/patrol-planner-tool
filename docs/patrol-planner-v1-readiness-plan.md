# v1.0 前四项必做工作与验收标准

当前版本保持 `v0.3.0-alpha`，完成以下四项后再定 beta/release。

## A. 应用内直接解析 DXF

### 目标

用户在网页选择 `.dxf`，本地服务自动转换并加载图层，不再要求用户运行脚本。

### 实施

- 前端上传到回环地址 `/api/import/dxf`，限制文件大小和来源。
- 后端临时保存原始 DXF，调用 `ezdxf + pyproj` 转换。
- 返回导入批次、管线 GeoJSON、设施 Point 要素、坐标系推断和核查报告。
- 坐标系不确定时必须暂停在预览确认页。
- 原始 DXF 不进入公开发布包和 GitHub。

### 验收

选择 DXF 后 30 秒内显示进度、管线数、设施数、边界和异常数；确认坐标系后自动加载高德底图。

## B. Windows 单文件安装包

### 目标

用户双击安装包即可启动，不要求安装 Python、ezdxf 或 pyproj。

### 实施

- PyInstaller 打包本地服务和依赖。
- 安装目录只放程序、前端资源和空配置模板。
- 用户配置目录存放高德 Key、导入批次和草稿。
- 安装器提供开始菜单快捷方式、端口检测和卸载入口。
- 生成 SHA256、版本号和离线安装说明。

### 验收

干净 Windows 机器安装后可启动网页、导入 DXF、完成坐标转换和路线规划；卸载不删除用户导出的路线文件。

## C. 真实设施块名映射验收

### 目标

不依赖猜测文字，依据实际 DXF 的图层名、块名、属性和文字标注识别阀门、井、调压设施、标志桩和阴保桩。

### 实施

- 对原始 DXF 统计 INSERT/POINT/TEXT/MTEXT 的图层和块名。
- 建立 `cad_layer_mapping.csv`：源图层、块名、文字编码、目标类型、坐标规则。
- 未识别对象进入报告，不静默丢弃。
- 抽样导出设施点图层，由业务人员在地图上逐项核对。
- 记录映射版本和验收人。

### 验收

每类设施都有“识别数量、漏识别数量、误识别数量、核查结论”；映射版本可重现同一批次结果。

## D. 道路吸附、道路侧别和合法折返算法

### 目标

让任务点和管线目标转换为可行驶道路上的控制点，并在最近合法路口折返，减少红圈所示无效绕行。

### 实施顺序

1. 任务点匹配最近可行驶道路，保留原始任务点和行驶点两套坐标。
2. 识别道路方向、单行道、中央隔离和道路侧别。
3. 从道路服务段构建候选路口和合法掉头节点。
4. 为双侧管线生成去程/回程覆盖段。
5. 将控制点按服务段拆分调用高德，再合并路线并保留每段诊断。
6. 以覆盖率、绕行率、掉头合法性和总里程进行评分。

### 验收

- 道路外任务点显示匹配距离和匹配道路。
- 禁止掉头、单行道和无桥连接不会被当作可折返。
- 规划结果显示每个折返点的道路和原因。
- 对截图中的红圈案例，系统能说明是合法绕行、道路吸附偏差还是算法缺陷。
